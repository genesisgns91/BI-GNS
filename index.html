Importe o relatório de embalagem padrão em Fontes de dados para ver esta análise.

Como ler

Necessárias = ⌈demanda do período ÷ múltiplo (peças por embalagem)⌉, item a item. Atendidas = cobertas por embalagens já em estoque; a produzir = sem estoque para cobrir.

Plano padrão = a quantidade da etiqueta é múltiplo exato das peças da embalagem (provável uso). Plano alternativo = abaixo do múltiplo ou não múltiplo; provavelmente não usa esta embalagem.

Itens com mais de uma embalagem no relatório: a principal é a primeira linha; as outras aparecem como alternativas.

O botão Só demanda depois da data (barra do período) mostra itens sem entrega até a data inicial e com entrega depois.
